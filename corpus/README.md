# Corpus — LWS Pune graded psych dossiers

11 hand-graded SSB psychology dossiers (TAT, WAT, SRT, SDT), all assessed
**31 July 2026 by a single assessor** at LWS Pune / Dr. APJ Innovation School.
**923 typed assessor marks** extracted from scanned sheets with no text layer.

| file | what it is |
|---|---|
| [`CODEBOOK.md`](./CODEBOOK.md) | The derived rubric — notation, thresholds, lexical rules, vocabulary, per-slide difficulty, reconstructed stimuli |
| [`SCHEMA.md`](./SCHEMA.md) | Record shape and the mark taxonomy |
| [`COVERAGE.md`](./COVERAGE.md) | What is transcribed and what is not, per candidate |
| [`SECOND-ASSESSOR-LEDGER.md`](./SECOND-ASSESSOR-LEDGER.md) | **Every conclusion a second assessor settles**, with the test for each |
| `records/` | One JSON per candidate. **Gitignored — see below** |

## Privacy

`records/` is **excluded from version control** and must stay that way.

These are psychological self-disclosures from candidates who are mostly minors.
They carry real names, family detail, self-reported aggression, disclosed
personal difficulties and an assessor's written judgements about each person's
character. [`ARCHITECTURE.md` section 8](../ARCHITECTURE.md) governs candidate
psych data in the product; it applies just as much to these files on disk.

Before this material goes anywhere beyond a local machine:

1. **Confirm consent.** These were produced for coaching, not for building a
   product. Using them as training or evaluation data is a different purpose and
   needs LWS Pune and the candidates to have agreed to it.
2. **Pseudonymise.** Replace names with stable ids and hold the mapping
   separately, out of the repo.
3. **Decide retention.** How long the corpus is kept, and what deletion means
   once a model has been evaluated against it.

The test suite never reads `records/`. It reads
`src/scoring/__tests__/fixtures/corpus-counts.json`, which is generated by
`npm run fixture` and contains only pseudonymous ids and integers.

## Rebuilding

```bash
npm run fixture    # records/ -> pseudonymous count fixture (committed)
npm run evalset    # records/ -> 124 paired TAT stories (gitignored)
npm run measure    # what share of marks each layer can reproduce
npm test           # 116 tests, incl. 21 replaying real sheets
```

## Running the D5 bake-off

```bash
npm run eval                                  # baselines only, no credentials needed
npm run eval -- --model claude-opus-5         # measure a model
npm run eval -- --model claude-opus-5 --effort medium --limit 20
```

Baselines run on every invocation and are the floor any judge must clear:

| provider | exact agreement |
|---|---|
| always "LOW" | **50.4%** |
| random grade | ~12% |

The harness prints the majority baseline next to every score, plus collapse
detection, mean signed error and a per-slide breakdown, so a flattering number
is hard to report by accident. See [D12](../DECISIONS.md).

**What this eval cannot establish:** the grade distribution is LOW 50 / Just Avg
52 / AVG 6 / Good 1 / V. good 0. It can distinguish LOW from Just Avg and little
else — the upper half of the scale is untestable from this corpus.

## Status

Assessor marks are complete for all 11 candidates: **923 typed marks**.
TAT verbatim text is complete for **every story that exists on a scanned page**
— 124 paired stories, 8-11 per slide. Four stories are lost to missing sheet
pages and four were left blank by candidates; see [`COVERAGE.md`](./COVERAGE.md).
WAT and SRT item text remains sampled rather than exhaustive.

## Health warning

**One assessor, one day, 11 candidates — confirmed by LWS, no second marker
for this batch.** No inter-rater reliability is obtainable from the 31 July 2026
batch alone, and the assessor demonstrably applies his own SRT tense rule
inconsistently between sheets (corrected 15/16 times on one candidate, not at
all on another with the same construction).

This corpus is good enough to derive a rubric and sanity-check a grader. It is
**not** good enough to support a claim of validated agreement, and
[`ARCHITECTURE.md` section 9](../ARCHITECTURE.md) still applies: output is
directional coaching feedback, never psychometric validation.
